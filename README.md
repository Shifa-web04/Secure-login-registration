# 🔐 NEXORA AUTH
### Secure Login & Registration UI

NEXORA AUTH is a modern, responsive login and registration interface developed using HTML, CSS, and JavaScript. It features a sleek dark-themed design with cyan accents and interactive form validation.

## ✨ Features

- Modern dark-themed interface
- Responsive layout
- Login and registration forms
- Login and registration tab switching
- Show/hide password functionality
- Password strength indicator
- Email validation
- Confirm password validation
- Remember Me option
- Terms and conditions checkbox
- Interactive error and success messages

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📁 Project Structure

```text
Secure-Login-Registration/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

## 🧪 Testing

The project was tested for form interactions, password visibility, password strength feedback, input validation, and responsive design.

## ⚠️ Important Note

This is a frontend demonstration project. It does not include backend authentication, database integration, or real account creation.
